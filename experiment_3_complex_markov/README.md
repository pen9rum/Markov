# Experiment 3: Complex Markov Players

Runnable code for the complex Markov-player experiments.

Main scripts:

- `scripts/run_generation.py`: run blind generation for complex Markov player sets.
- `scripts/run_identification.py`: run identification for complex Markov player sets.
- `scripts/check_sim_results.py`: check generated simulation outputs.
- `scripts/export_sim_results.py`: export generated simulation results.
- `scripts/compute_cumulative_metrics.py`: compute cumulative metrics.
- `scripts/summarize_identity_condition.py`: summarize results by identity-correctness condition.
- `scripts/check_repeats_and_strict_windows.py`: inspect repeated generations and strict-window behavior.
- `scripts/report_repeat_details.py`: report repeat diagnostics.

Plotting and paper-figure scripts are intentionally excluded from this release branch.
