# Experiment 2: Blind Generation

Runnable code for the blind trajectory-generation experiment.

Main scripts:

- `scripts/simulate_trajectory.py`: run blind generation experiments from context histories.
- `scripts/check_sim_results.py`: check generated simulation outputs.
- `scripts/compute_cumulative_metrics.py`: compute cumulative metrics from generated outputs.
- `scripts/compute_slump_metrics.py`: compute slump and degradation metrics.
- `scripts/export_sim_results.py`: export generated simulation results.
- `scripts/summarize_identity_condition.py`: summarize results by identity-correctness condition.

Plotting scripts are intentionally excluded from this release branch.
