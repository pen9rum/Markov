# Experiment 1: Strategy Identification

Runnable code for the strategy-identification experiment.

Main scripts:

- `scripts/batch_experiment.py`: run batches of simulated games and LLM identification calls.
- `scripts/batch_parser.py`: parse saved model outputs.
- `scripts/evaluate_metrics.py`: evaluate parsed outputs.
- `scripts/export_metrics_csv.py`: export evaluation summaries to CSV.
- `scripts/generate_prompts.py`: generate prompts for the identification task.
- `scripts/parse_analysis.py`: parse individual analysis outputs.

Plotting and paper-figure scripts are intentionally excluded from this release branch.
